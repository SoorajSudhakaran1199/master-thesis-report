\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
 
Press brake sheet metal bending is an important manufacturing process, but robotic implementations often still require manual programming. Operators define motion sequences, teach waypoints, and adapt programs for each new workpiece, which increases effort and limits flexibility.

This thesis presents an automated planning system for robotic press brake bending. The approach combines workpiece orientation determination, constraint-based grip planning, automatic regrip handling, and trajectory generation in a modular pipeline driven by geometric input and configuration data. The system generates robot programs without manual waypoint definition and includes validation steps for safe and feasible execution.

Evaluation in a virtual simulation environment covers varying workpiece dimensions, arbitrary initial orientations, regripping, and opposite-face bending. The results show executable robot programs and reduced programming effort compared with manual programming, supporting adaptable press brake automation for flexible manufacturing.

\vspace{1em}
\noindent\textbf{Keywords:} robotic press brake bending; automatic robot program generation; grip planning; regrip planning; trajectory generation; flexible manufacturing.
