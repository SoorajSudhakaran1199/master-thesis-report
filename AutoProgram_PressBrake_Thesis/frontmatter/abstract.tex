\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Press brake sheet metal bending is a key manufacturing process; however, despite the availability of robotic programming tools, implementations often rely on manual programming. Operators must define motion sequences, teach waypoints, and adapt programs for each new workpiece, resulting in increased effort and limited flexibility.

This thesis presents an automated planning system for robotic press brake bending. The proposed approach integrates workpiece orientation determination, constraint-based grip planning, automatic regrip handling, and trajectory generation within a modular pipeline driven by geometric input and configuration data. The system generates execution-ready robot programs without manual waypoint teaching and incorporates validation steps to ensure safe and feasible operation, requiring only bend-side selection from the operator.

The system is evaluated in a virtual simulation environment using repeated workflow and feasibility trials. The evaluation covers nominal direct bending on Side~A, opposite-side bending on Side~E, geometry variation, workpiece position variation, regrip-required scenarios, and failure-prone conditions. The results show that automated generation substantially reduces preparation effort while maintaining feasible simulated execution within the evaluated scenario set.

\vspace{1em}
\noindent\textbf{Keywords:} robotic press brake bending; automatic robot program generation; grip planning; regrip planning; trajectory generation; flexible manufacturing.
