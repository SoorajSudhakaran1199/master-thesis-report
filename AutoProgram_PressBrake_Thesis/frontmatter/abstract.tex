\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
 
Press brake sheet metal bending is a key manufacturing process, but many robotic implementations still depend on manual programming. Operators must define motion sequences, teach waypoints, and adapt programs for each new workpiece configuration, which increases programming effort and limits flexibility.

This thesis proposes an automated planning system for robotic press brake bending that reduces manual intervention and adapts to variations in workpiece geometry, orientation, and placement. The approach combines workpiece orientation determination, constraint-based grip position planning, automatic regrip handling, and trajectory generation within a structured planning pipeline.

The system is implemented as a modular software architecture driven by geometric input parameters and configuration data. It generates complete robot programs without manual waypoint definition and includes validation mechanisms for safe and feasible execution.

The system is evaluated in a virtual simulation environment using representative scenarios with varying workpiece dimensions, arbitrary initial orientations, regripping, and opposite-face bending. The results show valid executable robot programs and reduced programming effort compared with conventional manual programming. Overall, the approach supports more adaptable robotic press brake automation for flexible manufacturing.

\vspace{1em}
\noindent\textbf{Keywords:} robotic press brake bending; automatic robot program generation; grip planning; regrip planning; trajectory generation; flexible manufacturing.
